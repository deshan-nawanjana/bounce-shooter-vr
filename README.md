# WebXR-Based VR Shooting Game

Bounce Shooter VR is a browser-based immersive experience built using Three.js and the WebXR API, designed to run across a wide range of VR-enabled devices and compatible browsers. Players dual-wield virtual blasters using motion controllers to shoot physics-driven plastic projectiles at randomly positioned targets that appear within a fixed depth range in a 3D environment.

Launch Now: [https://deshan.lk/apps/bounce-shooter-vr](https://deshan.lk/apps/bounce-shooter-vr)

## Key Features

- Dual-wield VR shooting using motion controllers for immersive gameplay.
- Randomized target spawning across a fixed depth plane for dynamic aiming.
- Hit detection powered by collision systems.

## Libraries and Frameworks Used

- [Three.js](https://threejs.org/) - JavaScript 3D Library
